    Cambios sin publicar

      Conexión con GitHub

      Cómo crear el token (una sola vez)
      1. Entra en GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
      2. Ponle un nombre (por ejemplo "Panel XYZ") y una caducidad.
      3. En Repository access elige Only select repositories y marca solo este repositorio.
      4. En Permissions → Repository permissions → Contents elige Read and write. No hace falta nada más.
      5. Genera el token, cópialo y pégalo arriba. Se guarda solo en este navegador; cualquiera con acceso a este navegador podría publicar, así que úsalo en un equipo tuyo.

      Sin GitHub

      También puedes descargar los archivos y subirlos a mano a la carpeta datos/ del repositorio (y las imágenes nuevas a tierlist/).
